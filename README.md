## 📚 About

This repository contains the practical implementations for the **Deep Learning Lab (7CS4-21)** of the **VII Semester B.Tech. Computer Science & Engineering** curriculum under **Bikaner Technical University**.

The practicals focus on fundamental and advanced concepts in Deep Learning, including neural networks, gradient-based learning, backpropagation, convolutional neural networks and modern ConvNet architectures.

The repository is intended for:

* 🎓 Academic laboratory work
* 💻 Practical demonstrations
* 🧪 Experimentation with Deep Learning frameworks
* 📖 Viva and practical examination preparation
* 🚀 Further experimentation and learning

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/adithedev/Deep-Learning-Lab-VII-Semester-BTU.git
```

### Enter the repository

```bash
cd Deep-Learning-Lab-VII-Semester-BTU
```

### Install dependencies

```bash
pip install numpy matplotlib pandas
pip install torch torchvision
pip install tensorflow keras
```

For experiments requiring additional packages, install the dependencies specified inside the respective notebook.

---

## ☁️ Google Colaboratory

The practicals can be executed using **Google Colaboratory**.

Open a notebook in Colab and select:

```text
Runtime → Run all
```

Some experiments may require downloading datasets or configuring Kaggle credentials.

**Do not commit credentials such as `kaggle.json`, API keys, passwords or `.env` files to this repository.**
