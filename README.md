## 📚 About

This repository contains the practical implementations for **Deep Learning Lab (7CS4-21)** of the **VII Semester B.Tech. Computer Science & Engineering** curriculum under **Bikaner Technical University (BTU)**.

The practicals cover fundamental and advanced Deep Learning concepts including neural networks, gradient-based learning, backpropagation, convolution, pooling and major Convolutional Neural Network architectures.
